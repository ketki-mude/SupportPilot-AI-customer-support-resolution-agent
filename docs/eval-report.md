## Definitions

- **Correct resolution:** the intent (when the case checks it), final action, and approval requirement all match the expectation, nothing forbidden happened, and the run did not crash.

- **Tool-call success:** successful audited tool calls over all attempted ones. Cases that inject shop failures lower it on purpose.
- **Latency and cost:** summed over a ticket's agent runs, excluding the time a ticket waits for a supervisor.
